# FaceRecognitionAttendance

This is my college project named FaceRecognitionAttendance. It is a Python-based project that uses a webcam to recognize faces and automatically mark attendance.

Features:
- Admin Login system
- Register new students with webcam
- Automatic attendance marking using face scan
- View student and attendance records

Technologies Used:
- Python
- OpenCV (for face detection)
- CustomTkinter (for GUI)
- SQLite (for database)

How to Run:
1. Install required libraries: pip install -r requirements.txt
2. Run the project: python app.py
